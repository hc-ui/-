# 100 · 锁定文案

普通短视频 / 知识口播。NEW。只打「临时方案住进主干」。

## 整段口播

大家好。临时方案，住进了主干。上线那天先绕过去，说好下周再改。一周过了，绕路还在主干上。不是没人记得，是能跑就不想动。临时补丁，成了默认路径。新同学进来，只看见这条绕路。正式方案，一直停在草稿里。对照只打这一点，临时必须写搬家日。当天就记下，谁负责、哪天拆。到了那天，要么拆掉，要么升格。没搬家日的临时，就是永久。别让绕路，变成唯一的路。主干上只留能解释的路径。临时住进主干，当天开一张搬家票。到点就搬，别再拖。绕路可以过今晚，不能过冬天。没截止日期的，请当成已经住下来了。
