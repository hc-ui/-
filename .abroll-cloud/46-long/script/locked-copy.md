# 46 锁稿（加长 · 钝感策略）

原短切 5 句 / 10.5s。本版 18 句，五拍齐全，瞄准 40–50 秒。不改题，不抢 16 / 28 / 45。

大家好。杂务按六十分及格交付。不是偷懒。是把力气留给正事。行政杂务，当成换工位的租金。租金交完就行。别交成主业。工位卫生，收发快递，盖章跑腿。这些都按六十分做。标准只有一条，不出差错。六十分就过，别追求九十分。多一分，就少一分给课题。做完即止，清单勾上就停。别把卫生做成作品集。别在杂务上评优。评优那分别投，情绪也别跟进去。这不是你的战场。过了就走，把满分留给该满分的事。

## 五拍

1. **钩子**：杂务按六十分及格交付。
2. **诊断**：不是偷懒，是把力气留给正事。
3. **例子一（租金）**：行政杂务当租金，交完就行，别交成主业。
4. **例子二（及格现场）**：卫生 / 快递 / 盖章按六十分；考卷 60 过、90 不追；清单勾上就停。
5. **收束**：别在杂务上评优；过了就走，满分留给正事。
