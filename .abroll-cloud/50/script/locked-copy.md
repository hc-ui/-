# 50 锁稿（加长 · 利益同盟）

原短切 5 句 / 13.3s。本版 18 句，九镜，五拍齐全，瞄准 40–50 秒。不改题，不抢 14 / 15 / 16 / 28 / 46–49。

大家好。绑定一个主力博士。不是广撒网。是结成一条利益同盟。别同时绑三个师兄。力气一散，谁也不把你当自己人。认准一位稳的、有论文任务的师兄。高年级，手上有论文在推。性格稳，不天天改方向。你帮他搭自动化、处理数据。平台里最烦的活，你接下来。他减负，你才有位置。换署名、专利位次、毕业数据授权。署名栏多一个名字。数据盘盖上可引用。只绑这一条线。别再去认第二个主力。一条线绑牢，署名和数据才会来。

## 五拍

1. **钩子**：绑定一个主力博士。
2. **诊断**：不是广撒网，是结成一条利益同盟。
3. **例子一（选人）**：别同时绑三个；认准稳的、有论文任务的高年级。
4. **例子二（交换）**：你给自动化和数据处理；换署名、专利位次、可引用数据。
5. **收束**：只绑这一条线；一条线绑牢，署名和数据才会来。

口播禁：测控生态位、时间切片、报销、下一期、时长、文件名、链接、真名。
