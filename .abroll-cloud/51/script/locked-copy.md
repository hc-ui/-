## 口播全文

大家好。热门一来，很容易把Agent当成现在就要押上的职业主线。它不是当前唯一主线，而是一条长期第二技能树。主树要先长控制和机器人，AI只当手段，不抢根。错法是把整条精力条倒进Agent这一棵，主树停长。主桌堆满工具牌，独立小项目却还没亲手做完。侧牌可以慢慢攒，先别抢主桌的位置。接口、检索、技能这些牌，先堆在旁边，不上桌。以后可以交叉机器人和Agent，当前先别并成一条线。基础没过关，这些只保持兴趣，不占主精力。主线别停，副线别抢戏，两棵树别抢同一桶水。Python过关以前，Agent先靠边站。

## 五拍

1. 钩子：热门把 Agent 当成现在就要押的主线
2. 诊断：不是当前唯一主线，是长期第二技能树；主树先长控制与机器人
3. 例子拍（错）：精力条倒进 Agent，主桌堆满工具牌，小项目没做完
4. 例子拍（正）：侧牌慢慢攒、先堆旁边不上桌；交叉以后再说
5. 收束：基础没过关只保持兴趣；Python 过关前 Agent 靠边
