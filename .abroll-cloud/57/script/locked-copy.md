# 57 锁稿

来源：`topics-batch3.md` #57；Drive 只读工厂 `13_对照卡`。钩子不改。为覆盖 40–50 秒补「多的点下一张再打」一对 A/B，不是注水定格。

```
大家好。知识口播最容易胖的，不是字多，是一屏同时打三枪。观众眼睛只能停在一个对照上。左边是错法，右边是做法。一张对照卡，只打一个点。信息图不是目录墙，是反差。你要他记住的，不是五条建议，是那一对对错。多出来的点，先别上这张卡。一屏只留一对。第二对会把第一对冲掉。两对叠在一起，一张都记不住。多的点，下一张再打。先画左右两边，再写要他带走的那一句。对照没画完，金句先别写。下回做卡片，先画对照，再写金句。
```
