# 64 锁稿

来源：`topics-batch3.md` #41 原文（成片号被占用，本集用 64 首拍）。钩子不改。十五句，瞄准四十到五十秒。只打容器出生地点，不讲从值找键，不用等号盖列表，不拆函数，不跳语言。

```
大家好。点一次菜单，成绩册就空了。不是字典坏了，是空字典建在了循环里面。空花括号写进了循环里头，每进一轮就重建一次。每选一次菜单，整本成绩被揉成白纸。容器的出生地点，决定它能不能活过下一轮。循环外建，才能活过下一轮。循环里建，每进一次门就重建一次。空字典在门外建，别在门里重建。门外建一次，门里只读写，不再新建。先让菜单能退出，再增和列出。先把出生地点写对，别急着加新语法。对照只打这一点：门外建，门里不重建。写循环之前，先问字典出生在哪。出生在门外还能留下，出生在门里下一轮就是空的。
```
