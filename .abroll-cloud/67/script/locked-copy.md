# 67 锁稿

来源：工厂 `67_置顶了也不看`。钩子不改。为覆盖四十到五十秒补「位置不是阅读 / 第一句写动作 / 点名比钉子管用」，不是注水定格。不跟 41「新人提问」抢题——本条打的是钉子代替不了阅读。

```
大家好。置顶了也不看。你以为钉在顶上，他就一定打开。置顶只是位置，不是阅读。群里红点消了，人已经滑走。顶上那条还在，没有人点开。别把钉过当成看过。通知到了，不等于看完。他看见置顶两个字，手已经往下划。要他看，第一句就写动作。谁做、做什么、做到哪天。别只写请看置顶。置顶旁边再点一次名。点名比钉子管用。写完检查，别只靠置顶。钉子钉得再高。没有动作，他还是不看。先写动作，再决定钉不钉。
```

## 五拍

1. **钩子**：置顶了也不看。
2. **诊断**：置顶只是位置，不是阅读。
3. **例子一**：红点消了，人已经滑走。
4. **例子二**：第一句写动作；再点一次名。
5. **收束**：先写动作，再决定钉不钉。
