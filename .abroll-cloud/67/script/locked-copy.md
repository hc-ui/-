# 67 锁稿

来源：工厂 `67_置顶了也不看`。钩子不改。为覆盖四十到五十秒补「位置不是阅读 / 第一句写动作 / 点名比钉子管用」，不是注水定格。不跟 41「新人提问」抢题——本条打的是钉子代替不了阅读。

```
大家好。置顶了也不看。你以为钉在最顶上，他就一定会打开。置顶只是一个位置，不是一次阅读。群里红点消了，人已经从群里滑走。顶上那条还钉着，没有人真正点开。别把钉过一次，当成他看过一遍。通知送到了，不等于他看完了。他看见置顶两个字，手已经往下划。要他看，第一句就写清楚动作。谁来做、做什么、做到哪一天。别只丢一句请看置顶。置顶旁边再点一次具体的名。点一次名，比再钉一次管用。写完自己检查一遍，别只靠置顶。钉子就算钉得再高。没有动作，他还是不会看。先写动作，再决定钉不钉。
```

## 五拍

1. **钩子**：置顶了也不看。
2. **诊断**：置顶只是位置，不是阅读。
3. **例子一**：红点消了，人已经滑走。
4. **例子二**：第一句写动作；再点一次名。
5. **收束**：先写动作，再决定钉不钉。
