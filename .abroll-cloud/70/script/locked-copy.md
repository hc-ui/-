# 70 锁稿

来源：工厂 `70_例子先于概念`。钩子不改。为覆盖四十到五十秒补「抽屉名 / 荷叶水珠 / 例子前移」，不是注水定格。不跟 06「先给场景再给方法」抢题——本条打的是术语和例子的顺序，不是方法和场景。

```
大家好。例子先于概念。术语甩在前面，听众只会点头。他听见一个新词，点头，转身就忘。不是他笨，是你先给了标签，没给能摸到的场面。名字记住了，场面对不上，下次还是用不上。概念是抽屉上的名字。例子才是抽屉里的东西。先打开抽屉给人看，再念那个名字。比如先说水珠站在荷叶上不塌，再点表面张力。别先甩三个音节，再解释它是什么。写讲义的时候，把第一句术语往后挪。开场先落地一个能看见的例子。听众对上了场面，那个词才接得住。写完开场，把例子挪到概念前面。
```
