# 72 锁定口播（NEW · 四十到五十秒）

来源：`topics-batch4.md` #72。十八句。只打整段口播的结论位置，不抢 11 / 70 / 55 / 65 / 27 / 06。

大家好。先给结论再展开。背景铺完，结论还在最后一句。听众已经走了。能带走的那句，要放在最前面。整段口播，结论要在头上。先铺背景的稿，听起来认真。人却留不住。你还在交代从哪来。他已经滑走。结论埋在尾巴，前面全是垫。先把能复述的那句扔出去。再补为什么，再补从哪来。为什么叠在后面，不抢第一屏。写完口播，把结论拎到开头。对照一下，结论在尾还是在头。长铺垫先划掉，结论先落地。先给能带走的那句，再展开。

## 五拍

1. **钩子**：先给结论再展开。
2. **诊断**：背景铺完，结论还在最后一句；听众已经走了。
3. **例子一（整段位置）**：能带走的那句放最前；整段口播结论在头；先铺背景留不住人。
4. **例子二（为什么在后）**：先扔能复述的那句；为什么叠在后面，不抢第一屏。
5. **收束**：对照结论在尾还是在头；长铺垫划掉，结论先落地。
