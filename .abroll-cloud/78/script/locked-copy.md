# 78 锁定口播（NEW · 四十到五十秒）

来源：`topics-batch4.md` #78；Drive `方向测试.md` 2026-08-17。十八句。只打「先问有没有人想看」，不拍战神/仙侠，不重讲成片 45 会议结束时间。

大家好。先问有没有人想看。不是先问模型能不能做对。纯画面验证失败以后，最稳的方向被否了。它是壁纸，不是片子。没人物，没欲望，没失败。第一次看会哦一声。第三次手指就滑走。能做对的空镜，也没人停下来。顺序反了，就会反复推出零欲望方案。第一步，先问有没有人想看。第二步，再问模型能不能做对。有人看的欲望，排在能做对前面。没有人物，就没有人跟着走。没有失败，就没有人想看结局。技术上漂亮，情感上为零。先欲望，再模型。没人想看的方向，请当成没立。

## 五拍

1. **钩子**：先问有没有人想看。
2. **诊断**：最稳的方向是壁纸；没人物、没欲望、没失败。
3. **例子一（划走）**：第一次哦一声，第三次滑走；能做对的空镜没人停。
4. **例子二（顺序）**：先问有没有人想看，再问模型能不能做对。
5. **收束**：先欲望再模型；没人想看的方向请当成没立。
