# 81 锁稿（NEW · 请假带两方案）

成片 37 约十三点二秒，主钩是先摸惯例再书面报备。本版十六句，十二镜，瞄准四十到五十秒。不改题，不抢 37 / 05 / 16 / 79 / 28。不念真名，不念话术全文。

大家好。请假别空手交假条。随假带上两套方案。假条下面钉着汇报稿。导师要的是能选，不是听你解释。只交一句对不起，他只能驳。方案一，组会开头先汇报，再去上课。方案二，课后补做，或者下次补上。两张卡并列，让他勾一张。别只写主观理由。培养方案是刚性的，把冲突写清楚。不念话术全文，只交结构和选项。空手请假，等于把决定扔回去。附件先交上，人再离开。他勾哪张，你就按哪张走。带两方案，才算请过假。

## 五拍

1. **钩子**：请假别空手交假条；随假带上两套方案。
2. **诊断**：假条下钉稿；要能选，不是听解释；只道歉只能驳。
3. **例子一（两案）**：开头先汇报再上课；课后或下次补；并列勾一张。
4. **例子二（对照）**：主观理由打叉；培养方案刚性；只交结构不念全文。
5. **收束**：空手等于扔回决定；附件先交人再走；勾哪张按哪张；带两方案才算请过假。
