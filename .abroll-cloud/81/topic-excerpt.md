# 81 请假带两方案（云端 NEW 摘录）

来源：Drive 只读 `记忆库：中科大赵刚课题组·控制专硕生存与自救备忘录` 第三节 2「课程冲突应对三步法」第三步、第三节 3 报备结构。`topics-batch4.md` 第 81 条。成片 37 只把第一步第二步拍成题，第三步只在十三点二秒短切里带过一句。本集只认领第三步，云端新拍四十到五十秒。

- **钩子**：请假别空手交假条。随假带上两套方案。
- **交付**：假条下面钉着汇报稿。导师要的是能选，不是听你解释。
- **两案**：组会开头先汇报再去上课；课后补做或下次补上。两张卡并列，让他勾一张。
- **对照**：别只写主观理由；培养方案刚性，把冲突写清楚。不念话术全文，只交结构和选项。
- **收束**：空手请假等于把决定扔回去。他勾哪张就按哪张走。带两方案，才算请过假。
- **避开**：成片 37 主钩「先摸惯例再书面报备」；工期大饼；真名；话术全文当口播。
