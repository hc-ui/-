# 82 锁定口播（NEW · 四十到五十秒）

来源：`topics-batch4.md` #82。十六句。只打「空容器别直接算，先用 if not 拦住」，不讲空字典出生地，不拆函数，不跳异常整章，不跳语言。

大家好。空容器别直接算，先用 if not 拦住。空班级一上来就求最高分，程序当场炸掉。空列表喂给最大值，或者拿人数去除总分，都会崩。不是字典写错地方，是空了还硬算。现在你只会写长度等于零。if not 这一句，还没当成正式语法。空字典、空列表、空字符串，碰到 not 都算空。先问是不是空的，空了就停，别往下算。有人了，再求最高分、最低分、平均分。对照只打这一道闸。空了先拦住，有人再统计。写统计之前，先问班级空不空。一算就炸，是因为没拦。拦过再算，成绩才站得住。没拦住的空容器，请当成会炸。

## 五拍

1. **钩子**：空容器别直接算，先用 if not 拦住。
2. **诊断**：空班级求最高分炸掉；空列表喂最大值或除以零都会崩。不是出生地，是空了还硬算。
3. **语法**：现在只会写长度等于零；if not 还没当正式语法；空字典/列表/字符串碰到 not 都算空。
4. **闸门**：先问空不空，空了就停；有人再统计。
5. **收束**：写统计之前先问空不空；没拦住的空容器，请当成会炸。
