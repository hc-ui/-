# 83 锁稿（NEW · 旧方案套不上新问题）

工厂短切约十五点五秒，只有成片没有口播稿。本版十八句，十二镜，瞄准四十到五十秒。不改题，不抢 64 空字典 / 62 验收 / 61 试点 / 29 故事锁。不念真名。

大家好。旧方案套不上新问题。去年那套能跑的办法，拿到今年就对不上。问题已经换了皮，模板还是旧的。人还在按旧步骤往新题上套。硬套上去，缝会裂开。不是执行不力，是尺寸不对。旧约束已经不在了，你还当它在。先别急着改旧稿，先写下这次新在哪。边界变了，约束变了，目标也变了。能留的留下，对不上的重写。别把旧流程图硬拉长。别把旧提示词再改两个词。别拿上学期的课表套这学期。对照卡摊开，新条件对旧步骤。对得上的步骤才复用。套不上的地方立刻停手。新问题先量尺寸，再裁新布。

## 五拍

1. **钩子**：旧方案套不上新问题；去年能跑，今年对不上；皮换了模板没换。
2. **诊断**：还在按旧步骤硬套；缝会裂开；不是执行不力，是尺寸不对；旧约束已经不在。
3. **动作**：先写下这次新在哪；边界、约束、目标；能留的留下，对不上的重写。
4. **反例**：旧流程图硬拉长；旧提示词改两个词；上学期课表套这学期。
5. **收束**：对照卡新条件对旧步骤；对得上才复用；套不上停手；先量尺寸再裁新布。

口播禁：验收、试点、空字典、再优化、下一期、时长、文件名、链接、真名。
