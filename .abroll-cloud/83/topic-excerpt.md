# 83 旧方案套不上新问题（云端 NEW 摘录）

来源：Drive 只读工厂 `64_旧方案套不上新问题`（claim：15.458 秒短切，夹内仅封面与成片，无口播稿）。`topics-batch4.md` 原第 64 条。成片号 64 已被 `64-空字典写在循环外面.mp4` 占用，本集改认 83。云端新拍四十到五十秒，不拷工厂短切。

- **钩子**：旧方案套不上新问题。去年那套能跑的办法，拿到今年就对不上。
- **诊断**：问题已经换了皮，模板还是旧的。硬套上去缝会裂开。不是执行不力，是尺寸不对。
- **动作**：先别急着改旧稿。先写下这次新在哪。边界、约束、目标变了就记下来。能留的留下，对不上的重写。
- **反例**：别把旧流程图硬拉长；别把旧提示词再改两个词；别拿上学期的课表套这学期。
- **收束**：对照卡摊开，新条件对旧步骤。对得上才复用。套不上就停手。新问题先量尺寸，再裁新布。
