# 85 锁稿（NEW · 毕业底线三件套）

备忘录第一节 3。十六句，十二镜，瞄准四十到五十秒。不改题，不抢 14 / 15 / 16 / 49 / 50。不念真名。

大家好。毕业底线就三件套。不是医学顶刊，也不是把湿实验扛完。第一件，按时开题。第二件，工程型学位论文过盲审。第三件，挂上专利或论文。学院只认这三张卡。三件打满，导师按流程签字。别拿博士的顶刊当自己的线。硕士过关，是最低标准打满。开题拖过窗口，后面全堵死。论文要过盲审，不是写得漂亮就行。专利或论文，名字挂上去才算数。缺一件，流程停在门口。先钉这三件，再谈别的。底线打满，毕业才走得动。

## 五拍

1. **钩子**：毕业底线就三件套；不是顶刊，也不是扛完湿实验。
2. **三件**：按时开题；工程型学位论文过盲审；挂上专利或论文。学院只认这三张卡。
3. **过关**：三件打满才签字；别拿博士顶刊当线；硕士是最低标准打满。
4. **对照**：开题窗口一拖全堵；盲审不是写得漂亮；名字挂上才算；缺一件停门口。
5. **收束**：先钉这三件；底线打满，毕业才走得动。
