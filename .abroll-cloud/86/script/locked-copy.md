# 86 锁定口播（NEW · 四十到五十秒）

来源：`topics-batch4.md` #86。十八句。只打「成绩先存盘才能过夜」，不讲循环出生地，不拆函数，不包输入，不报文件名。

大家好。成绩加完了，关程序就没了。不是菜单坏了，是成绩只活在内存里。内存里的本，窗口一关就散。不是点一次菜单被揉成白纸。是整本程序关了，成绩才散掉。只打这一个过夜点，循环出生地先放下。退出前先把成绩写到盘上。下次打开，先从盘上读回来。打开的时候先读，退出的时候先写。盘上有本，关了还能回来。内存里的本，关了就没了。对照只打这一点。先把成绩存盘，再关程序。写进菜单之前，先问成绩落没落盘。加进去了却没落盘，等于没记下。落了盘再退出，成绩才能过夜。没存盘的成绩，请当成会丢。

## 五拍

1. **钩子**：成绩加完了，关程序就没了。
2. **诊断**：只活在内存里；窗口一关就散。不是这一轮菜单清空，是整本程序关了才散。
3. **做法**：退出前写到盘上；下次打开先读回来。打开的时候先读，退出的时候先写。
4. **对照**：盘上有本还能回来；内存里的本关了就没。先把成绩存盘，再关程序。
5. **收束**：落了盘再退出才能过夜；没存盘的成绩请当成会丢。
