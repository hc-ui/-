# 87 锁稿

来源：`topics-batch4.md` #87。钩子不改。十八句，瞄准四十到五十秒。只打「大案例先拆到能退出」。不念三道短题，不拆函数，不起名字，不讲空字典，不讲存盘，不跳语言，不说下一期，不报时长。

```
大家好。大案例先拆到能退出。不是缺语法，是增列统计焊死了退门。一上来四件事一起上，菜单卡死出不去。退门焊死，程序就停不住。先让退出通，别急着加功能。退出通了，才算有门。门没开，增和列都进不去。再做增加和列出，成绩才能进出。最后才做统计，最高最低平均往后排。先活下来，再往里装东西。对照只打这一点。先拆到能退出，再增和列出。统计是第三步，不是开工第一枪。整坨焊死，一改就炸。拆到能退出，才能停得住。大案例先拆开，先让退出通。退出通了，这盘才算站住。
```

## 五拍

1. **钩子**：大案例先拆到能退出。
2. **诊断**：增列统计焊死退门；四件事一起上，菜单卡死出不去。
3. **做法**：先让退出通；再增和列出；统计放最后。
4. **对照**：整坨焊死一改就炸；拆到能退出才能停。
5. **收束**：退出通了，这盘才算站住。
