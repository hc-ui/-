大家好。学术放养，工位收紧。题怎么推，他很少下场。算法推导他不改，控制回路他不盯。底层代码，他基本不碰。重大项目靠博士扛，硕士细节自己消化。别把放养当成没人管。椅子空着，才是大事。工位要人在，实验室要看得见。通知说不准哪天来，周末也可能叫人。假日前夕，临时会说开就开。他抓的是物理在场，不是推导对不对。宏观讲得多，比喻听完就散。别等学业指引，也别等情绪支持。职业契约摆正就行。放养的是学术，收紧的是工位。人坐住，题自己啃。

## 五拍

1. **钩子**：学术放养，工位收紧；题怎么推他很少下场。
2. **学术轨**：推导不改、回路不盯、代码不碰；博士扛项目，硕士自己消化。
3. **工位轨**：放养不是没人管；空椅子是大事；人要看得见。
4. **例子（通知）**：周末也可能叫；假日前夕说开就开；抓在场不抓推导。
5. **收束**：宏观比喻散掉；别等指引和支持；契约摆正；人坐住，题自己啃。
