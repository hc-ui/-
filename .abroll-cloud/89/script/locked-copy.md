# 89 锁稿（NEW · 本地实习等成果锁定）

来源：`topics-batch4.md` #89。十八句。只打「本地实习要等成果锁定」。

不跟 47 抢钩子：不讲脱产、查岗、空座位、车票。
不跟 48 抢钩子：不讲远程、双屏、仿真、线上项目、人在工位活在线上。

大家好。本地实习，等成果锁定。不是现在就去问本地岗位。专利或论文初稿没锁，先别探本地岗。研一现在去问，问早了。成果没盖章，人一挪，答辩就悬。先把毕业成果锁死。专利交出去，或者论文初稿定稿。锁死了，才有资格谈本地。时间窗在研二下，或者研三。合肥本地兼职，阶段性离校，都等这一步。杂活还握在手里，本地岗先灰掉。交给新一届，交接清单勾完。交接没写清，人别挪。没锁之前，本地实习先停。锁了，交了，再探本地。成果先锁，杂活先交。先等成果锁定，再谈本地。

## 五拍

1. **钩子**：本地实习，等成果锁定；不是现在就去问。
2. **诊断**：初稿没锁先别探；研一问早了；没盖章人一挪答辩就悬。
3. **例子一（锁定）**：专利交出去或论文初稿定稿；锁死了才有资格谈；时间窗在研二下或研三。
4. **例子二（交接）**：杂活还在手里先灰掉；交给新一届，清单勾完；没写清人别挪。
5. **收束**：没锁之前先停；锁了交了再探；成果先锁，杂活先交；先等成果锁定，再谈本地。

口播禁：脱产、查岗、空座位、车票、远程、双屏、仿真、线上项目、人在工位活在线上、真名、下一期、时长、文件名、链接。
