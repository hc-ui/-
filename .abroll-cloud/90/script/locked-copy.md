大家好。课题做完，别把领域身份一起背走。从课题里抽可带走的能力。留下的是场景，抽走的是方法。温控台前，抽闭环和建模，不是养细胞。采集脚本里，抽传感器进代码，不是试剂名。别把整段湿实验写进下一份工。简历写会建回路、会处理数据，别写我做过生医。换组换厂还能接着用，才叫抽走了。列一张可迁移清单：处理、控制、建模、采集、自动化。每做完一块，改成下一份工也能用的句子。领域名可以留在论文里。能力名要能单独站得住。课题是矿，不是籍贯。矿留下，件带走。抽走可迁移件，人才能走。

## 五拍

1. **钩子**：课题做完别背走领域身份；从课题里抽可带走的能力。
2. **诊断**：留下场景，抽走方法。
3. **例子一（台前 / 脚本）**：温控抽闭环建模不是养细胞；采集抽传感器进代码不是试剂名。
4. **例子二（简历）**：湿实验别写进下一份工；写会建回路、会处理数据，别写做过生医。换组换厂还能用才叫抽走。
5. **收束**：五件清单；改成下一份工也能用的句子；领域名留论文，能力名单独站；课题是矿不是籍贯；抽走可迁移件，人才能走。
