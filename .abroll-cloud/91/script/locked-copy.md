# 91 锁稿（NEW · 日志为什么出事才去翻）

指定名「分不清改物理和画错的片头纪律」与成片 38 同题，本版不拍。工厂短切约三十一点九秒。本版十六句，十一镜，瞄准四十到五十秒。不改题，不抢 38 / 69 / 84 / 92 / 93 / 95。不念真名。不拷工厂成片。

大家好。日志总是出事才去翻。不是平时太忙。是平时翻了也看不懂。看不懂，就等于没记。先写下三条必看字段。时间、用户、错误码。少一条，就翻不出来。每条请求带同一个追踪号。从头跟到尾，只认这一个号。入口、服务、下游，都跟这一个号。各写各的号，对不上。没有追踪号的日志，不准进生产。进了生产，出事只能猜。按这三步记。出事才翻得出来。

## 五拍

1. **钩子**：日志总是出事才去翻；不是平时太忙。
2. **诊断**：平时翻了也看不懂；看不懂等于没记。
3. **字段**：先写下三条必看字段；时间、用户、错误码；少一条就翻不出来。
4. **追踪号**：每条请求同一个号；入口服务下游都跟这一个号；各写各的号对不上。
5. **收束**：没号不准进生产；进了生产出事只能猜；按这三步记，出事才翻得出来。
