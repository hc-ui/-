## 五拍

1. **钩子**：课题可以偏生医，就业栈别焊死在生医上。
2. **诊断**：长期栈指向能换房间的能力，不是指向培养箱。
3. **例子一（入口）**：工入口别只留给体外诊断；实习只投生仪厂等于焊进一间实验室。
4. **例子二（选修 / 夜读 / 指向）**：选修只抱生医仪器进不去别的房间；夜读只翻细胞手册栈跟湿台走；岗位名没有细胞也可以投；栈指向控制、机器人、系统。
5. **收束**：生医是房间不是城；交差可以窄栈不要跟着窄；先报系统稳住，别报待过哪类实验室；焊死则下一扇门关上；栈指向房间外面，人才能走出去。
