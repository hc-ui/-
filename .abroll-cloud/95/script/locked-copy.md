# 95 锁定口播（NEW · 四十到五十秒）

来源：`topics-batch4.md` #95。十八句。只打「学完立刻用一次」，不讲三道短题，不讲例子先于概念，不讲体力杂务。

大家好。学完了，立刻用一次。看完教程以为会了，合上书就不会了。笔记攒了一堆，手上没留下一次。不是没学，是学完没有当场交手。教程还摊着，手却空着。下一页翻得很快，上一页却带不走。合上教程之前，先自己写一遍。不看答案，先交一次。刚记下一条，立刻拿手头题用一次。写错了也算用过，没写才是没学。用完这一次，再往下翻。看过却没用过，等于没学完。笔记不是学会，对照只打这一点。先用一次，再记下一页。当场交一次手，这一页才算合上。用过一次，才算学过。没立刻用过的，请当成没学完。

## 五拍

1. **钩子**：学完了，立刻用一次。看完以为会了，合上就不会了。
2. **诊断**：笔记一堆，手上没留下一次。不是没学，是没当场交手。下一页翻得快，上一页带不走。
3. **做法**：合上之前先自己写一遍。不看答案先交一次。刚记下一条，立刻用一次。写错了也算用过。
4. **对照**：看过没用过等于没学完。笔记不是学会。先用一次，再记下一页。
5. **收束**：当场交一次手，这一页才算合上。用过一次才算学过。没立刻用过的，请当成没学完。
