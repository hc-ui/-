# G 盘成片落盘（出片代理必读）

依据：Drive 记忆库 `本机公共路径与强制约束.md`（2026-09-14，Codex `MEM-20260914-02`）、`AI项目归档与交付工作流.md`（2026-09-12）。  
本页只复述现行规则。禁止另起目录，禁止写用户本机 C:\ / D:\。不搬盘、不重拍、不多路并行出片。

## 成品只进这里

```
AI视频项目\<NN_中文项目名>\
  00_最终成片_<中文题>.mp4
  00_封面_<中文题>.*
  项目说明.md
  项目状态.json
  assets\  audio\  plan\  script\  output\
```

- 新项目、素材、工程、中间文件、封面、成片，全部进该项目夹。
- 成品名必须是 `00_最终成片_*`，封面必须是 `00_封面_*`。都在项目目录里，不进根目录。
- 网盘根对应记忆库的 `G:\我的云端硬盘\`。正式项目根是其下的 `AI视频项目\`。
- 已有同题项目夹就用现成的，不新建平行夹、不另开「成片/」。
- 已有 `00_最终成片_*` 不静默覆盖；要换新片先把旧片挪进 `99_回退副本`，并经当次确认。

## 云端中转

`/workspace/成片/` 只是 VM 中转，不是 G 盘子目录。

1. 成片先落到 `/workspace/成片/<NN>-<中文题>.mp4`（连字符中转名）。
2. 工程内同时保留 `.abroll-cloud/<NN>/00_最终成片_<中文题>.mp4`。
3. **能传 Drive**：只上传到对应 `AI视频项目\<NN_中文项目名>\00_最终成片_*`（封面同理）。不要传到 `01` 或 `云端成片-ArollBroll`。
4. **传不了**（Drive MCP 的 `create_file` 只收整段 base64，约 1MB 以上 mp4 会失败）：留在 `/workspace/成片/`，在项目说明里写清目标 G 路径，停止。不发明第二套上传夹。

目标 G 路径写法（示例，NN 与中文题换成当集）：

```
G:\我的云端硬盘\AI视频项目\<NN_中文项目名>\00_最终成片_<中文题>.mp4
G:\我的云端硬盘\AI视频项目\<NN_中文项目名>\00_封面_<中文题>.jpg
```

## 草稿

- 云端草稿、镜头、配音、时间轴、核验：`/workspace/.abroll-cloud/<NN>/`。
- 本机 / Drive 渲染临时文件：`AI视频项目\_scratch\<项目或任务>\`。
- 草稿、镜头、缓存、上传状态 md **不进** `/workspace/成片/`，也 **不进** 任何网盘「成片」夹。
