# 时长硬规则（兄弟必读）

开新的 **A-roll + B-roll 知识口播** 之前，先读本文件。本文件管新片，不管剧情短剧，不管已交付成片（未另下指令不要返工 10–15s 旧片）。

只在本 Linux VM。禁止 `C:\` `D:\` `G:\`。本轮不上传 Drive。

---

## 硬指标

| 项 | 数 |
|----|----|
| 成片时长 | **必须 30–60 秒** |
| 目标 | **约 40–50 秒** |
| 禁止 | **10–15 秒**（4–5 句收工那种） |
| 规格 | 1080×1920，H.264 + AAC，竖屏知识口播 |

`ffprobe` 时长落在 30.00–60.00s 才算过。不到 30s 不算成片。超过 60s 砍口播，不要靠冻帧或静音尾巴。

旧片大量是 10–15s（如 46≈10.5s、51≈12s、54≈11.8s）。那是旧标准。新片对标 25 / 27 / 40 / 41（约 31s）再**多一个例子拍**，落到 40–50s。

---

## 怎么拉长（用内容，不用冻帧）

时长必须来自**锁定口播**和**真切镜**，不是后期垫。

### 1. 锁定口播加长：8–12 句

`script/phrases.txt` / `locked-copy.md` / `voiceover.txt` 先锁，再配音，再组 A/B。

- **必须 8–12 句**（含「大家好」）。4–5 句必然只有 10–15s，直接重写。
- 每句能单独切一镜。一句一个判断，不要把三段塞进一句。
- 口播结构固定五拍，缺一拍就补：
  1. 钩子（现象）
  2. 诊断（不是 X，是 Y）
  3. **例子拍**（错法或现场，具体到能画 B 卡）
  4. **再多一个例子拍**（正法、对照、或另场同一纪律）
  5. 收束（一句可执行）
- 豆包语速下，8–12 句口语大约 35–50s。句数不够就不要进 `produce.py`。

对标：

- 不合格：`51/script/phrases.txt` 5 句 → 约 12s
- 不合格：`54/script/phrases.txt` 5 句 → 约 12s
- 下限：`40/script/phrases.txt` 14 句 / 9 镜 → 31.8s（刚过 30，新片还要再加一个例子拍）
- 下限：`41/script/phrases.txt` 11 句 → 30.5s
- 句数够：`25/script/phrases.txt` 15 句 → 31.1s

### 2. 更多 A/B 交替

白底小灯 A-roll 说判断，黑底卡 B-roll 给对照。不要五镜收工。

- **至少 7–9 镜**，按 `A → B → A → B → A → B → A` 交替。
- 钩子可连续两镜 A（挥手 + 摊手），之后必须切开。
- 每个例子拍至少一对 A/B：A 说判断，B 出对照卡。多一个例子拍 = 至少再多一对 A/B。
- 禁止：一整段口播只切 1–2 张 B 卡；禁止 B 卡当目录墙、一屏打三枪。

对标：`40/plan/shot_recipe.json` 9 镜（A 挥手/摊手/指向 → B 一句议题 → A → B 一个分歧 → A → B 先定七天 → A 点赞）。新片在此基础上再插一对「例子」A/B。

### 3. 多一个例子拍

「多一个例子拍」不是把同一句换个说法，是**另一场能画出来的具体场面**。

- 已有「错法」就补「正法」；已有原则就补「现场一句对话 / 一行操作 / 一块对照」。
- 例子要能独立做一张 B 卡，不要只在口播里顺嘴提。
- 这一拍通常再吃 8–15s，是 31s 走到 40–50s 的正当来源。

### 4. 禁止冻帧垫时长

不准用静帧、末帧克隆、空镜、黑场、静音尾巴把短片撑到 30s。

- `produce.py` 里 `tpad=stop_mode=clone` 只允许补不到 0.3 秒的切镜对齐误差。单镜克隆超过 0.5 秒必须重做该镜（加口播、换更长 A 素材、或重画带运动的 B-roll）。
- 不准靠 `setpts` 把 A 镜慢放到「慢动作演讲」。A 镜略拉一点可以，不能靠它凑整十秒。
- 不准在口播结束后挂 2s+ 定格或空 B 卡。
- 口播短、画面长 = 失败。先加句，再重配音，再重切。

## 交片前自检

1. 已读本文件。
2. `phrases.txt` 8–12 句；`voiceover.txt` 与之一致。
3. `shot_recipe.json` ≥7 镜，A/B 交替，含**两个**可画的例子拍。
4. 配音时长本身已 ≥30s（不是画面垫出来的）。
5. `ffprobe` 成片 30–60s，目标 40–50s。
6. 整段 `ffmpeg -f null` 能解完。
7. 未写盘符路径，未传 Drive。

口播禁令照旧：不说「下一期」、不报时长、不念文件名、不念链接、不念屏幕上的字。
